Kane's Wrath Patch Switch - R25j Fixes R3
Local release based on the verified R25j Fixes R2 core.
Includes four official R25j map archives and four updated custom maps.
The game and WorldBuilder skip missing 4K files. The 4K add-on is separate.

Extract the complete ZIP with a ZIP64-capable extractor. Close the game and
WorldBuilder, then run Install.cmd under your usual Windows account with
permission to write to the game folder. Enter the folder containing CNC3EP1.exe.
The installer verifies files, backs up replaced files, and rolls back on failure.
Use the same patch and map versions on every multiplayer PC.
